# Anime Search Engine Server 🎬🔍

Este es el backend y servidor principal para el motor de búsqueda de anime. Está construido con **Node.js** y **Express**, utilizando una arquitectura modular para facilitar el mantenimiento, el escalado y la gestión de rutas de búsqueda dinámica.

---

## 🚀 Características

*   **Arquitectura Modular:** Separación clara de rutas, controladores y lógica de negocio.
*   **Búsqueda Dinámica:** Endpoints optimizados para consultar y filtrar datos de anime de forma eficiente.
*   **Servidor Express:** Configuración ligera, rápida y lista para producción o entornos de desarrollo.

---

## 🛠️ Tecnologías Utilizadas

*   **Node.js** (Entorno de ejecución)
*   **Express.js** (Framework web)
*   **JavaScript (ES6+)**
