Mi rol como Director del Proyecto:
Visión y Estética: Yo definí la línea visual "Premium" y los detalles de UX, exigiendo una consistencia absoluta en el diseño (como el color exacto de Crunchyroll y los bordes redondeados del tráiler).
Control de Calidad (QA): Actué como el filtro crítico, detectando fallos en la lógica de búsqueda y asegurando que ninguna actualización rompiera las funciones ya establecidas (como el sistema de favoritos o el despliegue del buscador).
Optimización de Código: Supervisé la limpieza del código para que fuera apto para correr en Termux, priorizando la eficiencia en el uso de la API y el manejo de la caché JSON.
Dirección Técnica: Guié la implementación paso a paso, asegurando que cada "capa" de código añadida respetara la integridad de las funciones anteriores, logrando un código final robusto y sin redundancias.

cabe aclarar que este no es un proyecto hecho con alguna ambición el mero objetivo de esto es ayudarme a comprender las funciones y significados de cada linea utilizada
para ayudarme a comprender y expandir mi basico conocimiento sobre progamacion y desarrollo web y claro como una mejor manera de aprender a base de error-correccion.
